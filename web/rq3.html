RQ3

Computational Cost

What is the computational cost of the baseline, SBFL, and hybrid slicing approaches — in execution time and peak memory — and does the hybrid approach's extra slicing step add meaningful overhead?

Purpose

This research question evaluates the computational cost of the experiments by analyzing execution time and system resource usage across all buggy versions. It reports how long the baseline, SBFL, and hybrid approaches each take, how much additional time the dynamic-slicing step itself requires, and how much peak memory the pipeline consumes — helping identify which projects and buggy versions are computationally expensive, and whether the hybrid approach's benefits (RQ1–RQ2) come at a meaningful runtime cost.
