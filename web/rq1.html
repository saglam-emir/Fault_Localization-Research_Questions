RQ1

Test Suite Characteristics

What do the test suites of the evaluated Defects4J buggy versions look like, in terms of passing and failing test cases, static assertions, and failures that never reach an assertion at all?

Purpose

This research question characterizes the test suites used across all experiments, before any slicing or fault-localization technique is applied. It reports how many tests pass and fail per buggy version, how many static assertion call sites back those tests, and how often a failure terminates the test before it ever reaches an assertion. This context matters because every later result — the size of a dynamic slice, the rank of a fault line — is downstream of what the test suite actually exercises.
