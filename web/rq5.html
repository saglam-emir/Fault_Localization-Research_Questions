RQ5

Fault Localization Ranking

How effectively do the trace-based and slice-based rankings locate the actual faulty line?

Purpose

RQ5 evaluates how effectively the fault localization approaches rank the actual faulty lines. In addition to exact line matches, the analysis considers the distance between the predicted and actual faulty locations, letting you interactively investigate how localization success changes when a small positional deviation is accepted — without ever moving the prediction itself, only the tolerance used to judge it.
