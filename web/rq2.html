RQ2

Search-Space Reduction

How much does dynamic program slicing shrink the statement search space compared to the full test-suite execution trace, and how consistently does it do so across projects?

Purpose

This research question investigates the core promise of the hybrid approach: that restricting fault localization to a dynamic slice, instead of the full execution trace, meaningfully narrows the set of statements a developer or ranking algorithm has to consider. The full execution space is every statement any test touches; slicing computes, for each failing assertion, only the statements that could have influenced it. This section quantifies the gap between the two.
